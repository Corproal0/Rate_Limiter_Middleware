# Rate Limiter Middleware on Go

Лёгкий и производительный **HTTP Rate Limiter Middleware** для Go, реализующий алгоритм **Token Bucket** (ведро с токенами). Защищает ваш API от спама, DDoS-атак и перегрузок, ограничивая количество запросов с одного IP-адреса.

##  Особенности

* **Алгоритм Token Bucket**: гибкое управление лимитами с постепенным пополнением токенов.
* **Потокобезопасность**: правильная работа с конкурентностью (`sync.Mutex`) без взаимных блокировок (Deadlocks).
* **Автоматическая очистка памяти**: фоновый процесс удаляет неактивные IP-адреса по истечении `CleanupTTL`.
* **Чистая архитектура**: легко подключается к любому `http.Handler` или стандартному `http.ServeMux`.
